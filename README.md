# 🌤️ Weatherly - Weather App

A responsive weather application that provides real-time weather information and a 7-day forecast for cities around the world.

The application uses the **Open-Meteo API** to fetch weather data and its geocoding API to search and identify locations.

## ✨ Features

- 🔍 Search for cities worldwide
- 💡 Smart location suggestions while typing
- 🌡️ Current temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌡️ Feels-like temperature
- 🌤️ Dynamic weather icons
- 📅 7-day weather forecast
- 🌙 Dark / Light mode
- 🌈 Weather-based background
- ☀️ Automatic day/night detection
- 🌡️ Celsius / Fahrenheit conversion
- ⌨️ Search using the Enter key
- ⏳ Loading animation
- ❌ Error handling for invalid cities
- 📱 Responsive design for mobile and desktop

## 🔌 APIs Used

### Open-Meteo Weather API

Used to retrieve:

- Current temperature
- Humidity
- Feels-like temperature
- Wind speed
- Weather conditions
- Day/night information
- 7-day forecast

### Open-Meteo Geocoding API

Used to:

- Search for cities
- Display location suggestions
- Retrieve latitude and longitude
- Identify administrative regions and countries

No API key is required.
